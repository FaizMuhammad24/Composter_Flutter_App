# Buku Panduan Penggunaan I-Compost Secara Komprehensif

Selamat datang di aplikasi **I-Compost** (Aplikasi Monitoring Kompos Berbasis IoT). Dokumen ini berisi **tutorial langkah demi langkah** untuk mengoperasikan seluruh fitur di dalam aplikasi, baik untuk akun **User (Penyetor)** maupun **Admin (Pengelola)**.

*(Catatan: Tempatkan screenshot/gambar aplikasi Anda di bawah setiap teks penanda [Gambar ...])*

---

## 🟢 BAGIAN 1: PANDUAN PENGGUNA (USER)

Ikuti langkah-langkah di bawah ini untuk mulai menyetorkan sampah dan menukarkan poin Anda!

### 1. Cara Mendaftar dan Masuk ke Aplikasi
1. Buka aplikasi I-Compost di ponsel Anda.
> *[Gambar 1.1 Tampilan Halaman Awal / Splash Screen]*
2. Jika Anda belum memiliki akun, tekan tulisan **"Buat Akun Baru"** di bagian bawah layar.
> *[Gambar 1.2 Tampilan Form Pendaftaran Akun]*
3. Ketikkan **Nama Lengkap**, **Username**, dan **Password** baru (minimal 6 karakter) pada kolom yang disediakan.
4. Centang kotak persetujuan Syarat & Ketentuan.
5. Tekan tombol **"Sign Up"**. Anda akan diarahkan kembali ke halaman awal.
> *[Gambar 1.3 Tampilan Notifikasi Pendaftaran Berhasil]*
6. Ketik username dan password yang baru saja Anda buat, lalu tekan **"Masuk"**.
> *[Gambar 1.4 Tampilan Halaman Login Saat Memasukkan Data]*

### 2. Cara Membaca Dashboard User
Setelah berhasil masuk, Anda akan berada di halaman Beranda (Dashboard). 
> *[Gambar 2.1 Tampilan Keseluruhan Dashboard User]*
1. Lihat bagian atas layar untuk memastikan sapaan nama Anda sudah sesuai.
> *[Gambar 2.2 Tampilan Bagian Header Profil]*
2. Perhatikan kartu hijau besar di tengah layar; di situ terdapat statistik **Total Disetor (kg)**, jumlah **Poin**, dan berapa kali hadiah **Ditukar**.
> *[Gambar 2.3 Tampilan Kartu Statistik Keseluruhan]*
3. Di bawahnya, terdapat bagian **Quick Action** yang berisi tombol cepat untuk **Setor Sampah**, **Riwayat Setor Sampah**, dan **Tukar Poin**.
> *[Gambar 2.4 Tampilan Tombol Quick Action]*
4. Jika Anda menggulir ke bawah, Anda juga dapat melihat daftar **Reward Terpopuler** serta membaca saran bermanfaat di bagian **Tips Kompos Hari Ini**.
> *[Gambar 2.5 Tampilan Reward Terpopuler dan Tips Kompos]*

### 3. Cara Menyetorkan Sampah Organik
1. Pada halaman Dashboard, tekan tombol **"Setor Sampah"**.
> *[Gambar 3.1 Tampilan Halaman Form Setor Sampah]*
2. Ketik perkiraan berat sampah yang akan Anda setorkan (dalam satuan Kg) pada kolom yang tersedia.
3. Tekan area kotak foto untuk mengunggah bukti gambar. Anda bisa mengambil foto langsung dari kamera atau memilih dari galeri ponsel.
> *[Gambar 3.2 Tampilan Pilihan Sumber Foto (Kamera/Galeri)]*
4. (Opsional) Ketik catatan tambahan jika ada (misalnya: "Sampah sisa potongan sayur").
5. Tekan tombol **"Kirim Setoran"**.
> *[Gambar 3.3 Tampilan Proses Loading Saat Mengirim Data]*
6. Setoran Anda telah terkirim! Statusnya saat ini adalah **Pending**. Poin Anda akan bertambah secara otomatis setelah Admin di lokasi menyetujui setoran Anda.
> *[Gambar 3.4 Tampilan Notifikasi Setoran Berhasil]*

### 4. Cara Menukarkan Poin dengan Hadiah
1. Pada halaman Dashboard, tekan tombol **"Tukar Hadiah"**.
> *[Gambar 4.1 Tampilan Halaman Katalog Hadiah]*
2. Gulir ke bawah untuk melihat daftar barang/reward yang tersedia di katalog.
3. Pastikan saldo poin Anda mencukupi, lalu ketuk salah satu hadiah yang ingin Anda tukar.
> *[Gambar 4.2 Tampilan Detail Item Hadiah yang Dipilih]*
4. Tekan tombol **"Tukar Poin"** di layar konfirmasi.
> *[Gambar 4.3 Tampilan Pop-up Dialog Konfirmasi Penukaran]*
5. Permintaan penukaran Anda berhasil dibuat dengan status **Pending**. Segera temui Admin komposter untuk mengambil barang Anda. Poin akan terpotong setelah Admin menyerahkan barang dan menekan tombol persetujuan di aplikasinya.
> *[Gambar 4.4 Tampilan Notifikasi Penukaran Berhasil]*

### 5. Cara Memantau Riwayat Transaksi
1. Tekan ikon **Jam (Riwayat)** yang berada di deretan menu bagian bawah layar.
2. Untuk mengecek status setoran sampah, pilih tab **"Riwayat Setoran Sampah"**. Anda bisa melihat apakah setoran Anda masih *Pending* (warna oranye), *Approved* (warna hijau), atau *Rejected* (warna merah).
> *[Gambar 5.1 Tampilan Tab Riwayat Setoran Sampah Beserta Statusnya]*
3. Geser ke samping (atau tekan tab sebelahnya) untuk masuk ke **"Riwayat Penukaran Hadiah"** dan pantau status barang yang sedang Anda klaim.
> *[Gambar 5.2 Tampilan Tab Riwayat Penukaran Hadiah]*

### 6. Cara Mengelola Akun
1. Tekan ikon **Profil** di pojok kanan bawah layar.
> *[Gambar 6.1 Tampilan Halaman Utama Profil User]*
2. Untuk mengubah kata sandi, ketuk opsi **"Ganti Password"**, masukkan password lama dan baru Anda, lalu tekan simpan.
> *[Gambar 6.2 Tampilan Halaman Form Ganti Password]*
3. Jika ingin keluar dari aplikasi, ketuk tombol **"Log Out"** di bagian paling bawah.
> *[Gambar 6.3 Tampilan Pop-up Dialog Konfirmasi Keluar/Log Out]*

## 🔴 BAGIAN 2: PANDUAN ADMIN (PENGELOLA)

Sebagai Admin, Anda bertanggung jawab mengontrol mesin komposter dan menyetujui aktivitas pengguna. Ikuti tutorial berikut untuk mengoperasikan panel Admin.

### 1. Cara Memantau Kondisi Komposter Secara Real-Time
1. Setelah masuk sebagai Admin, halaman pertama yang muncul adalah Dashboard IoT.
> *[Gambar 7.1 Tampilan Keseluruhan Dashboard Admin]*
2. Periksa tulisan **"Status Koneksi"** di bagian atas untuk memastikan alat terhubung (Online).
> *[Gambar 7.2 Tampilan Indikator Status Koneksi Online/Offline]*
3. Perhatikan 3 alat ukur melingkar (Gauge) di layar:
   - **Suhu (°C):** Pastikan suhu tidak melewati batas merah yang menunjukkan kondisi terlalu panas.
   - **Kelembaban (%):** Pantau kadar air kompos.
   - **Gas Metana (ppm):** Perhatikan lonjakan gas berbahaya.
> *[Gambar 7.3 Tampilan Detail Ketiga Gauge Sensor IoT]*
4. Anda dapat melihat ikon kipas, pemanas, dan pompa di layar yang menunjukkan status menyala/mati (Otomatis) berdasarkan nilai sensor saat itu.
> *[Gambar 7.4 Tampilan Panel Indikator Aktuator Otomatis]*

### 2. Cara Mengontrol Alat Komposter Secara Manual
1. Tekan ikon **Gear** di deretan menu bawah.
> *[Gambar 8.1 Tampilan Halaman Panel Kontrol Manual Aktuator]*
2. Di layar ini, Anda mengambil alih sistem otomatis.
4. Tekan tombol **"Motor Pengaduk"** jika kompos perlu diratakan.
5. Tekan tombol **"Pompa Air/EM4"** untuk memicu penyiraman. 
> *[Gambar 8.3 Tampilan Saat Tombol Pompa Air Berubah Warna Menjadi Aktif]*
6. Setiap tombol yang Anda tekan akan berubah warna sebagai tanda bahwa perintah sukses dikirim ke mesin komposter (ESP32).

### 3. Cara Memproses Setoran Sampah dan Penukaran Hadiah User
1. Tekan ikon **Folder (Manajemen)** di menu bawah. Di sini terdapat 4 pilihan menu.
> *[Gambar 9.1 Tampilan Daftar 4 Sub-Menu Utama Manajemen]*
2. Pilih **"Persetujuan Setoran Sampah"**:
   - Anda akan melihat daftar User yang baru menyetor sampah. 
   - Ketuk fotonya untuk memastikan bahwa sampah yang dibawa adalah organik dan beratnya sesuai.
> *[Gambar 9.2 Tampilan Daftar Persetujuan Setoran Sampah & Foto Bukti]*
   - Tekan tombol **Check (✅)** untuk menyetujui setoran, atau **Silang (❌)** untuk menolak. Poin User otomatis bertambah jika disetujui.
> *[Gambar 9.3 Tampilan Notifikasi Setoran Berhasil Disetujui/Ditolak]*
3. Pilih **"Persetujuan Penukaran Hadiah"**:
   - Jika ada User yang datang mengambil hadiah, cocokkan namanya di daftar ini.
> *[Gambar 9.4 Tampilan Daftar Persetujuan Penukaran Hadiah]*
   - Setelah Anda menyerahkan hadiah, tekan **Approve** agar poin User tersebut terpotong.
4. Pilih **"Kelola Hadiah"**:
   - Tekan tanda tambah (+) untuk memasukkan item hadiah baru beserta foto dan harga poinnya ke dalam katalog aplikasi.
> *[Gambar 9.5 Tampilan Form Tambah Item Hadiah Baru]*
5. Pilih **"Data Pengguna"**:
   - Gunakan menu ini untuk mengecek total poin dan username seluruh pendaftar I-Compost.
> *[Gambar 9.6 Tampilan Direktori Seluruh Data Pengguna]*

### 4. Cara Mengecek Status Sistem dan Mengunduh Data Rekap (CSV)
1. Tekan ikon **Server (Sistem)** di sudut kanan bawah menu navigasi.
> *[Gambar 10.1 Tampilan Halaman Utama Status Sistem]*
2. Anda dapat melihat informasi masa aktif mikrokontroler (*Uptime*) dan sisa memori (*Free Heap*) di bagian atas layar.
> *[Gambar 10.2 Tampilan Status Hardware Uptime & Free Heap]*
3. Periksa tabel **Analisis QoS** untuk mengecek apakah *Delay*, *Jitter*, dan *Packet Loss* internet alat IoT dalam kondisi stabil.
> *[Gambar 10.3 Tampilan Tabel Metrik Kualitas Jaringan (QoS)]*
4. Untuk menyimpan data ke dalam bentuk tabel (Excel), gulir ke paling bawah layar.
5. Tekan tombol **"Unduh Rekap Data (CSV)"**.
> *[Gambar 10.4 Tampilan Tombol Unduh Rekap Data CSV]*
6. Pilih apakah Anda ingin mengunduh log Sensor Komposter atau log QoS jaringan. File akan otomatis masuk ke folder `Download` di HP Anda.
> *[Gambar 10.5 Tampilan Notifikasi Berhasil Mengunduh File ke Perangkat]*

### 5. Cara Membaca Notifikasi Aplikasi
1. Tutup atau minimalkan aplikasi I-Compost Anda.
2. Jika ada User yang baru saja "Setor Sampah", ponsel Anda akan berbunyi dan menampilkan notifikasi pop-up.
> *[Gambar 11.1 Tampilan Pop-up Notifikasi Setoran Baru di Layar HP]*
3. Anda juga akan mendapat peringatan langsung dari ponsel jika suhu komposter melewati batas aman, sehingga Anda dapat langsung membuka aplikasi dan menyalakan Exhaust Fan.
> *[Gambar 11.2 Tampilan Pop-up Notifikasi Peringatan Suhu/Gas Ekstrem]*

### 6. Cara Mengatur Profil Admin
1. Tekan ikon **Profil** di pojok kanan atas dari panel Dashboard atau Sistem (jika tersedia).
> *[Gambar 12.1 Tampilan Halaman Profil Khusus Admin]*
2. Anda bisa mengubah kata sandi, mengganti foto, atau menekan tombol **Log Out** untuk mengakhiri sesi pengelolaan komposter Anda.
> *[Gambar 12.2 Tampilan Pilihan Pengaturan Profil dan Log Out]*

## ♻️ BAGIAN 3: ALUR LENGKAP MENABUNG SAMPAH (USER & ADMIN)

Bagian ini merangkum proses nyata (*End-to-End*) dari saat User membawa sampah hingga poin berhasil masuk ke akun.

1. **User Datang Membawa Sampah**
   - User memilah sampah organik di rumah dan membawanya ke fasilitas komposter I-Compost.
2. **User Mengisi Form Setoran di Aplikasi**
   - User membuka aplikasi, menekan **Setor Sampah**.
   - User menimbang sampah di lokasi, lalu memasukkan berat (Kg) ke dalam aplikasi.
   - User memfoto sampah tersebut sebagai bukti fisik dan menekan **Kirim Setoran**.
> *[Gambar 13.1 User Mengirim Form Setoran]*
3. **Admin Menerima Notifikasi**
   - Ponsel Admin akan berbunyi dan memunculkan notifikasi bahwa ada setoran baru yang menunggu persetujuan.
> *[Gambar 13.2 Notifikasi Masuk ke HP Admin]*
4. **Admin Melakukan Verifikasi Fisik**
   - Admin menghampiri User di lokasi komposter.
   - Admin mengecek jenis sampah (harus organik) dan memastikan berat di timbangan sesuai dengan yang diinputkan User di aplikasi.
5. **Admin Menyetujui Setoran di Aplikasi**
   - Admin membuka menu **Manajemen > Persetujuan Setoran Sampah**.
   - Admin mencocokkan foto dan data, lalu menekan tombol **Check (✅)**.
> *[Gambar 13.3 Admin Menyetujui Setoran di Aplikasi]*
6. **Sampah Dimasukkan & Poin Bertambah**
   - User/Admin memasukkan sampah tersebut ke dalam mesin komposter.
   - Poin User otomatis bertambah di aplikasi (1 Kg = 10 Poin) dan status riwayat berubah menjadi *Approved*. Transaksi menabung sampah selesai!
> *[Gambar 13.4 Poin User Bertambah di Dashboard]*

## 🎁 BAGIAN 4: ALUR LENGKAP PENUKARAN HADIAH (USER & ADMIN)

Bagian ini merangkum proses nyata (*End-to-End*) dari saat User mengklaim hadiah di aplikasi hingga Admin menyerahkan barangnya.

1. **User Memilih Hadiah di Aplikasi**
   - User memastikan saldo poinnya mencukupi, lalu membuka menu **Tukar Hadiah** di aplikasinya.
   - User memilih hadiah yang diinginkan dan menekan tombol **Tukar Poin**.
   - Status penukaran akan masuk ke tahap *Pending*.
> *[Gambar 14.1 User Melakukan Request Penukaran Hadiah]*
2. **User Menemui Admin di Lokasi**
   - User datang ke fasilitas I-Compost atau tempat Admin bertugas untuk mengambil hadiah secara fisik.
3. **Admin Mengecek Permintaan Penukaran**
   - Admin membuka aplikasi dan masuk ke menu **Manajemen > Persetujuan Penukaran Hadiah**.
   - Admin mencari nama User dan hadiah yang diklaim di dalam daftar permintaan.
> *[Gambar 14.2 Admin Mengecek Daftar Antrean Penukaran Hadiah]*
4. **Admin Menyerahkan Barang & Menyetujui di Aplikasi**
   - Admin mengambil barang fisik (misal: pupuk kompos jadi, bibit tanaman, dsb) dan menyerahkannya kepada User.
   - Setelah barang diterima User, Admin menekan tombol **Approve (✅)** pada aplikasi.
> *[Gambar 14.3 Admin Menyetujui Permintaan Penukaran]*
5. **Poin Terpotong & Transaksi Selesai**
   - Poin di akun User akan otomatis terpotong sesuai harga hadiah.
   - Status di riwayat User berubah menjadi *Approved*. Proses tukar hadiah berhasil!
> *[Gambar 14.4 Poin User Terpotong di Dashboard]*
